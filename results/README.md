# Performance Results

Run the benchmark script after compiling the programs:

```bash
make
python3 -m pip install matplotlib
bash scripts/benchmark.sh
```

The script generates:

- `sum_times.csv`
- `pi_times.csv`
- `sum_time_vs_processors.png`
- `sum_speedup.png`
- `pi_time_vs_processors.png`
- `pi_speedup.png`

Do not invent timing values. Performance depends on the computer or cluster used, so these files should be generated by running the programs on the environment used for the lab.

Speedup is calculated as:

`Speedup(p) = T1 / Tp`

where `T1` is the execution time using one process and `Tp` is the execution time using `p` processes.
